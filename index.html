Access & safety notes
Principles
  • Owner chooses which family members and advisors can view which documents.
  • In production, all files should be encrypted at rest and in transit, with location in India.
  • Emergency access rules (e.g., unlock certain docs only if both spouse + child approve).
  • Activity log to see who accessed / downloaded which document.
